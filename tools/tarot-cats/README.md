# Gatti delle carte dei tarocchi

Script che disegnano i gatti a pennellate (ispirati al gatto a linee di Lumira) e i simboli delle 22 carte.

    python3 cards.py   # scrive /tmp/catcards.json

Poi si copia il risultato in `apps/frontend/src/components/tarot/catArt.ts` (vedi lo script nella PR che l'ha introdotto).
